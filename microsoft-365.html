The problem

The inbox is your largest attack surface.

Microsoft 365 is easy to buy and easy to start using, which is why so many businesses are running it exactly as it arrived. The licences were chosen once and never reviewed. The security features they are paying for have never been turned on.

That matters because email compromise is the front door for payment fraud. Attackers do not hack systems so much as impersonate people, and a default Microsoft 365 set-up leaves the easy paths open.

Set up right once, managed continuously and invisible to your team: that is the standard. It closes those paths with verified sending domains, strong sign-in and alerts when something looks wrong.

Questions owners ask

Frequently asked questions

Which Microsoft 365 plan does a small business need?

It depends on the role. Business Basic covers web and mobile apps and email. Business Standard adds the desktop Office applications. Business Premium adds advanced security and device management. Many businesses need a mix, which is where the savings are.

Is Microsoft 365 secure out of the box?

Not fully. The tools are there, but conditional access, email authentication, phishing protection and alerting need to be configured. Many businesses are paying for security features that were never switched on.

How long does a Microsoft 365 migration take?

It depends on the number of mailboxes and the amount of data. We plan the move in advance and usually carry out the switch outside working hours, so that people arrive to find everything working.

Do we need to back up Microsoft 365?

Yes. Microsoft keeps the service running, but protecting your data against deletion, a departing employee or ransomware is your responsibility. See backup and disaster recovery.

Are we ready for Microsoft Copilot?

Copilot can reach whatever the user has permission to open. If file permissions have grown messy over the years, that needs to be put right first. We review and tidy access before AI tools are switched on.
